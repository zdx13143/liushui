# 流水

iPhone 上可用的微信 + 支付宝账单自动记账工具。纯前端单文件网页，上传官方导出的账单，自动解析、去重、分类、出报表。

数据全程只存在你手机的浏览器里，不上传任何服务器。

## 在线使用

https://zdx13143.github.io/liushui/

在 iPhone Safari 打开上面的地址，点底部「分享」→「添加到主屏幕」，之后从桌面图标进入，用起来跟 App 一样。

## 为什么不能读取实时账单

iOS 的沙箱机制不允许任何第三方程序读取微信、支付宝内部的数据，快捷指令也拿不到。所以「付完钱自动记一笔、零操作」在不越狱的 iPhone 上做不到。

可行的方式是：微信和支付宝都自带「把账单导出成文件」的功能，导出后在这里上传，几百笔账一次解析分类完。每月花约两分钟。

## 怎么用

### 第一步：导出微信账单

1. 微信 → 我 → 服务 → 钱包 → 账单
2. 右上角「···」→ 下载账单 → 用于个人对账
3. 选时间范围（一次最多一年）→ 填邮箱 → 输支付密码
4. 「微信支付」公众号会推送解压码和下载链接，下载文件

### 第二步：导出支付宝账单

1. 支付宝 → 我的 → 账单 → 右上角「···」
2. 开具交易流水证明 → 用于个人对账
3. 选时间范围 → 填邮箱 → 身份验证
4. 邮件附件就是账单，解压密码写在邮件正文里

### 第三步：上传

在本工具「导入」页选择文件即可。支持 `.csv` `.xlsx` `.xls`，也支持加密的 `.zip`——会弹窗让你填解压密码，不用回电脑上解压。

重复导入同一份账单不会重复记账，按订单号自动去重。微信一次最多导一年，多年的分几次导就行。

## 功能

- 自动识别是微信还是支付宝的账单，两套格式都认
- GBK / UTF-8 编码自动识别，支付宝账单不会乱码
- 内置约 400 条商户关键词规则，覆盖餐饮、交通、购物、居住、医疗、文娱、教育、人情往来、金融保险、生活服务、通讯充值
- 支付宝账单自带的「交易分类」字段直接复用
- 分类错了点一下就能改，改完自动记住，下次同类商户跟着走
- 统计口径可调：提现充值还款、转账红包、已退款、失败交易，默认剔除（这些不是真实消费）
- 月度概览、分类排行、占比饼图、近 6 个月趋势、支付方式分布
- 导出整理好的 CSV（带 BOM，Excel 直接打开不乱码）
- 可选的 AI 兜底：规则认不出的陌生商户，填个大模型 API Key 批量补全，只发送商户名不含金额

## 分类体系

支出：餐饮美食、交通出行、购物消费、居住物业、医疗健康、文娱休闲、教育培训、人情往来、金融保险、生活服务、通讯充值、其他支出

收入：工资薪酬、红包收入、退款返还、理财收益、转账收入、其他收入

## 隐私

- 所有解析、计算、渲染都在浏览器本地完成，数据存 localStorage，不离开设备
- 除你在设置页主动点「补全未分类」外，不会发起任何网络请求
- 账单文件不会上传到任何地方

## 本地运行

下载 `index.html`，双击用浏览器打开即可。也可以：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 已知限制

- 数据存在浏览器 localStorage（约 5-10 MB），清缓存会丢，重要数据记得导出 CSV
- 换设备需要重新导入，或用导出再导入的方式迁移
- 加密的 zip 只在传统 ZipCrypto 加密下能解开，极少数用 AES 加密的压缩包需要手动解压后上传 csv
